<theme-switcher>

A custom element that allows you to switch between light, dark, and system theme.

With custom styling

You can customize the colors of the theme switcher by defining CSS variables for each theme option. In this example, we have defined a few custom color palettes, but you can create your own by using any valid CSS color value (e.g., hex, rgb, hsl, etc.)

Code sample

For brevity reasons, only the CSS variables for the "Lime / electric" palette are shown below.

theme-switcher {
  color-scheme: light dark;

  --theme-switcher-background-color: light-dark(#f7fee7, #142004);
  --theme-switcher-border-color: light-dark(#bef264, #84cc16);
  --theme-switcher-option-color: light-dark(#3f6212, #d9f99d);
  --theme-switcher-option-active-color: light-dark(#ffffff, #172008);
  --theme-switcher-option-active-background-color: light-dark(#65a30d, #a3e635);
}
